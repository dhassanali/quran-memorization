# Domain docs

This is a single-context repo. Before exploring a feature, read the root `CONTEXT.md` and relevant ADRs under `docs/adr/` when those files exist. Proceed silently if they do not exist; domain-modeling creates them when terms or decisions are resolved.

Use terms defined in `CONTEXT.md` consistently. If a needed concept is missing, reconsider the term or note the gap for domain-modeling. Surface any conflict with an existing ADR rather than silently overriding it.
