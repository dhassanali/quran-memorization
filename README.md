# حِفظي — رحلة الحفظ

تطبيق لمتابعة حفظ القرآن ومراجعته بصفحات المصحف المدني (١–٦٠٤). بيانات الحفظ محفوظة محليًا في المتصفح.

## الاستخدام

تصفّح المصحف وانتقل بين السور والأجزاء والصفحات، أو ابحث عن آية، ثم أضف الصفحة المعروضة للمراجعة ضمن هدفك اليومي. في المراجعة تظهر كلمات الصفحة وآياتها. اضغط كل كلمة أخطأت في تسميعها مرة واحدة، ثم اختر «أنهِ المراجعة». إن خرجت قبل الإنهاء، تعود علامات الأخطاء عند فتح الصفحة مجددًا. الصفحة التي تضم أكثر من سورة لها موعد مراجعة واحد، وتُجمع أخطاء جميع كلماتها.

احفظ إشارة مرجعية من أسفل المصحف، وافتح «رحلتي» لرؤية الصفحات المستحقة، والتقدم نحو هدف اليوم، والإشارات المرجعية، وسجل المراجعات مع الكلمات التي حُدِّدت كأخطاء. تُحفظ الإشارات والسجل محليًا وتدخل الإشارات في النسخ الاحتياطية الجديدة؛ ويمكن استيراد النسخ القديمة دون إشارات.

يعتمد الموعد القادم على FSRS. تُحوّل نسبة الأخطاء إلى تقييم داخلي: صفر = سهل، حتى ٥٪ = جيد، حتى ١٠٪ = صعب، وأكثر من ١٠٪ = أعد. لا تظهر أزرار التقييم للمستخدم. تحتفظ الصفحات القديمة بموعدها الحالي حتى مراجعتها التالية، حيث تبدأ لها بطاقة FSRS.

تُحسب بداية اليوم، والصفحات المستحقة، والهدف اليومي حسب توقيت السعودية (`Asia/Riyadh`) بغض النظر عن توقيت الجهاز.

تتيح نافذة الإعدادات تغيير الهدف اليومي واللغة، وتصدير نسخة JSON من بياناتك أو استيراد نسخة لاستبدالها. لا تشمل النسخة محتوى القرآن القابل لإعادة التنزيل. افحص معاينة النسخة قبل تأكيد الاستبدال.

ينتقل البحث عن الآيات مباشرة إلى صفحتها باستخدام بيانات [quran-meta](https://github.com/quran-center/quran-meta) المرخّصة بـ MIT. يعمل البحث العربي محليًا بعد تحميل فهرسه أول مرة، لكن فتح صفحة لم تُحفظ مؤقتًا يحتاج إلى الإنترنت؛ ويحتاج البحث بلغات أخرى إلى الإنترنت.

يُحمّل محتوى الصفحة عند فتحها أول مرة ويُخزّن مؤقتًا في IndexedDB للمراجعات دون اتصال لمدة لا تتجاوز ستة أيام. بعد ذلك يلزم الاتصال لتحديث الصفحة. يتطلب فتح صفحة جديدة الاتصال بالإنترنت. يعمل خط عربي بديل دون اتصال؛ وقد يختلف شكله عن الخط القرآني المحمّل من الشبكة. يستعمل عرض الكلمات مواضع الأسطر من مصحف QCF V2 مع نص QPC Hafs، ويعرض عناوين السور والبسملة غير المرقّمة في الأسطر المخصصة لها. يضبط حجم الخط ليناسب عرض الصفحة، لكن الخط والتبرير قد يختلفان عن المصحف المطبوع. مصدر البيانات: [Quran Foundation page API](https://api-docs.quran.com/docs/tutorials/fonts/page-layout/).

## التطوير

يتطلب Node.js 22.12 أو أحدث.

```bash
npm install
npm test
npm run build
npm run dev
```

خطة التنفيذ والمراجعة في [CODE_REVIEW_PLAN.md](CODE_REVIEW_PLAN.md).

قرار مصادر المحتوى والمزامنة دون اتصال في [docs/offline-content.md](docs/offline-content.md). فهرس البحث العربي `src/verses.json` مولَّد من نص Tanzil Uthmani 1.1 المرخّص [CC BY 3.0](https://tanzil.net/docs/Text_License)، ويحفظ إشعار حقوق النشر كاملًا. لإعادة توليده من الملف الرسمي المحمّل من [Tanzil](https://tanzil.net/download/) شغّل `node scripts/build-search-index.mjs <path-to-quran-uthmani.txt>`؛ تتحقق الأداة من بصمة SHA-256 قبل الكتابة.
