# حِفظي — رحلة الحفظ

تطبيق عربي يعمل دون اتصال لمتابعة حفظ القرآن. يعتمد التطبيق على **صفحة المصحف** (١–٦٠٤) كوحدة أساسية، ويحفظ بياناتك في IndexedDB على جهازك، ويمنح كل صفحة جدول مراجعات متباعدًا مستقلًا.

## المزايا

- واجهة عربية من اليمين إلى اليسار مع لوحة رئيسية تركّز على المراجعات المستحقة.
- تقييم تسميع بخمس درجات، مع شرح واضح لتأثير كل درجة.
- هدف حفظ يومي قابل للتعديل، ومؤشرات فورية للتقدم اليومي والكلي.
- قائمة بالصفحات المحفوظة ومواعيد مراجعاتها القادمة.
- يعمل دون حساب أو خادم أو اتصال دائم بالإنترنت.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## جدولة مراجعات على نمط Anki

لكل صفحة معامل سهولة مستقل يبدأ من `٢٫٥`. تظهر أزرار التقييم مدة المراجعة التالية قبل اختيارها، وتُحدَّث السهولة بعد كل تسميع:

| التقييم | الأثر | الفترة التالية |
| --- | --- | --- |
| أعد | لم يُستدعَ الحفظ | يوم واحد، وتُسجل هفوة وتقل السهولة ٠٫٢ |
| صعب | استدعاء بمشقة | الفترة × ١٫٢، وتقل السهولة ٠٫١٥ |
| جيّد | استدعاء صحيح | الفترة × معامل السهولة |
| سهل | استدعاء واثق | الفترة × معامل السهولة × ١٫٣، وتزيد السهولة ٠٫١٥ |

لا يقل معامل السهولة عن `١٫٣`، لذلك لا تصبح الصفحة الضعيفة بعيدة الموعد عن غير قصد. تظل البيانات على جهازك، وتتبنى الصفحات السابقة الإعدادات الجديدة تلقائيًا عند أول مراجعة لها.
