# حِفظي — رحلة الحفظ

تطبيق عربي يعمل دون اتصال لمتابعة حفظ القرآن. يعتمد التطبيق على **صفحة المصحف** (١–٦٠٤) كوحدة أساسية، ويحفظ بياناتك في IndexedDB على جهازك، ويمنح كل صفحة جدول مراجعات متباعدًا مستقلًا.

## المزايا

- واجهة عربية من اليمين إلى اليسار مع لوحة رئيسية تركّز على المراجعات المستحقة.
- تقييم تسميع بخمس درجات، مع شرح واضح لتأثير كل درجة.
- هدف حفظ يومي قابل للتعديل، ومؤشرات فورية للتقدم اليومي والكلي.
- قائمة بالصفحات المحفوظة ومواعيد مراجعاتها القادمة.
- يعمل دون حساب أو خادم أو اتصال دائم بالإنترنت.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```
